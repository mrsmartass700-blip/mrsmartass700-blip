# 👵 Бабка: Кооп

Кооперативный хоррор в духе Granny: **2 игрока (до 4) против бабки‑ИИ**, мультиплеер по локальной сети / **Radmin VPN**.
Это не мод оригинальной игры, а своя игра с нуля. Весь код, модели, текстуры и звуки сделаны с нуля, чужих ассетов нет.

У вас есть 5 дней, чтобы выбраться из дома. Входная дверь в гостиной закрыта на три замка: **навесной замок** (ключ), **доски** (молоток) и **цепь** (кусачки).
Предметы каждый раз разложены по-новому, часть из них лежит в запертых **кладовке** и **кабинете** (к ним есть свои ключи).
Бабка ходит по дому, открывает двери, слышит шаги и скрип половиц, ставит капканы. Если она поймает кого-то из вас, наступает следующий день.

## Установка (Windows)

1. Скачайте папку `granny-coop` целиком (или весь репозиторий архивом ZIP).
2. Запустите **`SETUP.bat`**. Откроется мастер установки «Бабка Setup Wizard 98»:
   * если Node.js не установлен, мастер сам скачает портативную версию (в систему она не ставится);
   * мастер копирует игру, рисует ярлыки с бабкой, открывает порт в брандмауэре (Windows спросит права администратора), добавляет игру в «Программы и компоненты» и кладёт деинсталлятор;
   * по дороге встретятся лицензионное соглашение с бабкой, «тапок в 4K», проверка смелости и другие сюрпризы.
3. Запускайте игру ярлыком **«Бабка Кооп»**.

Без установщика тоже можно: поставьте [Node.js](https://nodejs.org) (LTS) и запустите `start.bat` (на Linux/macOS: `./start.sh`).

## Игра с другом по Radmin VPN

1. Оба ставите [Radmin VPN](https://www.radmin-vpn.com/ru/) и заходите в одну сеть: один нажимает «Создать сеть», второй «Присоединиться к сети».
2. **Хост** запускает игру (ярлык или `start.bat`). В консоли и в лобби будет адрес вида `http://26.x.x.x:7777`, отправьте его другу.
3. **Друг** ничего не устанавливает: он просто открывает этот адрес в браузере (Chrome / Edge / Firefox).
4. Друг нажимает «Я готов», хост выбирает сложность и нажимает «Начать игру».

Если друг не может подключиться, запустите у хоста `firewall.bat` (или «Пуск → Бабка Кооп → Открыть порт в брандмауэре»).
В одной домашней сети Radmin не нужен: подойдёт обычный локальный адрес из лобби.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / мышь | ходить / смотреть |
| Shift | бег (громко, тратит выносливость) |
| C или Ctrl | присесть (тихо) |
| E | открыть дверь, взять предмет, спрятаться в шкаф или под кровать, применить предмет к замку |
| G / Q | положить / бросить предмет (бросок шумит и отвлекает бабку, бутылка бьётся громко) |
| ЛКМ | перцовый баллончик (оглушает бабку, 3 заряда) |
| F | фонарик (без него вас видно хуже, но и вы видите хуже) |
| Z | метка для друга (видна сквозь стены) |
| T / Enter | чат |
| Tab | список задач |
| Esc | пауза (игра для остальных не останавливается!) |

## Сложность

Практика (без бабки) · Лёгкая · Нормальная · Сложная · Кошмар (свет в доме выключен).

## Как устроено

* `server/`: авторитетный сервер на Node.js без зависимостей (свой WebSocket), 20 тиков/с. ИИ бабки работает на сервере: A*‑поиск пути, зрение (FOV + прямая видимость), слух, состояния «патруль / проверить шум / погоня / поиск / оглушена».
* `shared/map.js`: карта дома и правила, общие для сервера и клиента.
* `public/`: клиент на three.js. Процедурные текстуры, модели из примитивов, звуки синтезируются через WebAudio (с позиционированием).
* `installer/`: мастер установки (PowerShell‑загрузчик + локальный Node‑бэкенд + интерфейс в стиле Windows 98).
* `test/`: `npm test` прогоняет логику игры, ИИ, сетевую игру двух клиентов и пробную установку.

Порт и сложность по умолчанию задаются в `config.json` (его создаёт установщик): `{ "port": 7777, "difficulty": "normal" }`.
Порт можно указать и при запуске: `start.bat 7778`.
